`@mainset/ui-core` — це незалежна від фреймворків основа mainset UI: дизайн-токени (кастомні
властивості CSS), CSS-класи для кожного елемента та _рецепти_ — невеликі функції, що
перетворюють стильові пропси на назви класів. [`@mainset/react`](https://github.com/mainset/ui-stack/tree/main/packages/react)
— тонкий адаптер поверх неї. Будь-який інший фреймворк або звичайний HTML використовує ті самі класи.

```html preview
<button
  class="ms-background ms-border ms-surface ms-surface--hover-all ms-surface--variant-solid ms-control ms-control--size-base ms-button"
>
  Зберегти
</button>
<button
  class="ms-background ms-border ms-surface ms-surface--hover-all ms-surface--variant-outlined ms-control ms-control--size-base ms-button ms-tone-base"
>
  Скасувати
</button>
<button
  class="ms-background ms-border ms-surface ms-surface--hover-all ms-surface--variant-soft ms-control ms-control--size-base ms-button ms-tone-error"
>
  Видалити
</button>
```

Приклад вище — звичайний HTML: кожен елемент у цій документації показано з його власними
класами, тож ви бачите саме те, що потрапить у продукт — у React, Vue, серверних шаблонах чи
статичній сторінці.

## Що всередині

| Частина   | Що це                                                                              |
| --------- | ---------------------------------------------------------------------------------- |
| Токени    | кастомні властивості `--ms-*`: палітра, семантичні кольори, тони, відступи, шрифти |
| Основа    | базові стилі з нульовою специфічністю, колірні схеми (`data-theme`), класи тонів   |
| Елементи  | набір класів `ms-*` для кожного елемента у двох шарах: механіка та вигляд          |
| Рецепти   | `buttonRecipe({ srfVariant: 'solid' })` → рядок класів для будь-якого шаблону      |
| Живі теми | `createTheme()`: ціла тема з одного кольору бренду, під час роботи або збирання    |

## Принципи

- **Налаштування на кожному рівні.** Токени на `:root`, на піддереві чи на одному елементі;
  кожен компонент читає їх через ланцюжок запасних значень, тож усі три працюють разом.
- **Композиція замість повторення.** Кнопка — це поверхня, контрол і механіка кнопки разом,
  а не копія їхніх оголошень.
- **Нульова специфічність.** Правила елементів обгорнуто в `:where()`, тож будь-який утилітарний
  клас або клас застосунку перемагає за будь-якого порядку завантаження.
- **Будь-який напрямок тексту.** Лише логічні властивості: розділ, що пишеться справа наліво,
  віддзеркалюється сам.
- **Старі браузери також.** Chrome 88, Firefox 78 і Safari 14.1 (2021) — з перевіркою під час збирання.
